# 📅 ربات تلگرام رزرو نوبت و سیستم یادآور خودکار

یک ربات تلگرام برای سالن‌های زیبایی، کلینیک‌ها یا کسب‌وکارهای خدماتی جهت مدیریت نوبت‌های مشتریان، نمایش لیست قیمت خدمات و ارسال پیام‌های یادآوری خودکار.

## 🌟 امکانات کلیدی
- **کاتالوگ خدمات:** نمایش دسته‌بندی‌شده خدمات و قیمت‌ها با دکمه‌های شیشه‌ای.
- **رزرو هوشمند:** کاربران زمان‌های خالی را انتخاب می‌کنند. سیستم از رزرو تکراری جلوگیری می‌کند.
- **یادآوری خودکار:** استفاده از `APScheduler` برای ارسال پیام یادآوری به مشتری (مثلاً ۲ ساعت قبل از نوبت).
- **پنل مدیریت:** مدیر می‌تواند نوبت‌های روز را ببیند، خدمات را مدیریت کرده و قیمت‌ها را آپدیت کند.
- **دیتابیس:** تمام اطلاعات مشتریان، نوبت‌ها و خدمات در PostgreSQL ذخیره می‌شود.

## 🛠️ تکنولوژی‌های استفاده شده
- **زبان:** Python 3
- **فریم‌ورک:** `aiogram`
- **دیتابیس:** `PostgreSQL`
- **زمان‌بندی:** `APScheduler`

## ⚙️ معماری و روند کار
- **جریان رزرو:** ماشین حالت (FSM) فرآیند رزرو را مرحله به مرحله هدایت می‌کند (انتخاب خدمت -> تاریخ -> ساعت -> تایید نهایی).
- **موتور یادآوری:** یک زمان‌بند در پس‌زمینه هر ساعت دیتابیس را چک می‌کند و برای نوبت‌های پیش‌رو پیام می‌فرستد.
- **مدیریت:** دسترسی‌های مبتنی بر نقش تضمین می‌کند که فقط مالک سالن بتواند قیمت‌ها را تغییر دهد یا نوبت‌ها را لغو کند.
